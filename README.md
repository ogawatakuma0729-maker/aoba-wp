# 青葉ワークス（WordPress見本）

小さな会社の会社サイト見本です。実在の会社ではありません。

できること：

- トップ、会社概要、事業、実績、採用、お知らせ（ブログ）、問い合わせ
- お知らせ・事業・実績・採用は管理画面から足せる
- 問い合わせ内容は管理画面の「問い合わせ」に残る（メール送信は別設定）
- 題名・説明文、住所・電話、測定番号の差込口
- スマホ幅への対応

相手のサーバーへ出すときは、相手の WordPress にこのテーマ（`themes/aoba`）を入れて有効化し、同じ名前のページを作ります。

![トップ画面](screenshot.png)

## 動かし方（このパソコン）

1. Docker Desktop を起動する  
2. このフォルダで `docker compose up -d`  
3. http://localhost:8080  

管理画面：http://localhost:8080/wp-admin（`admin` / `aoba-local`）

止めるとき：`docker compose down`

## 公開したあとにやること（本番）

1. Googleビジネスプロフィールに店情報を登録する  
2. サイト下の住所・電話と揃える  
3. 測定番号（G-）を外観 → カスタマイズ → 店情報・測定 に入れる  
4. サーチコンソールに `/wp-sitemap.xml` を渡す  
5. 週1回、検索の言葉と読まれたページを見て題名を直す  

## いまできないこと

会員、決済、ネットショップ、STUDIO、検索1位の約束。サーバー会社の契約そのものは相手が用意します。
