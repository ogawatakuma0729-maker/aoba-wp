# 青葉ワークス（WordPress見本）

小さな会社の案内サイトを、相手が文章を直せる入れ物（WordPress）に載せた見本です。実在の会社ではありません。

できること：

- トップ・サービス案内の表示
- 相談フォーム（画面上の受付まで。メールは飛びません）
- 管理画面からページ文章を直す
- 各ページの題名・説明文（検索・SNS用）
- サイトの地図（`/wp-sitemap.xml`）
- 店の名前・住所・電話・営業時間をページに出す（地図登録と揃える用）
- 訪問者の人数を数える番号を入れる場所（外観のカスタマイズ「店情報・測定」）

説明文は、固定ページの「抜粋」に書きます。空なら共通の説明が入ります。

## 動かし方（このパソコン）

Docker Desktop が入っている前提です。

1. このフォルダで `docker compose up -d`
2. 初回だけ、READMEに書いてある install のコマンド
3. http://localhost:8080

管理画面：http://localhost:8080/wp-admin  
ユーザー：`admin` / パスワード：`aoba-local`（このパソコン用）

止めるとき：`docker compose down`

## 公開したあとにやること（本番の店）

この見本の中だけでは、地図に本物の店は出ません。本番では次を相手と一緒にやります。

1. Googleで「ビジネスプロフィール」を開き、店の名前・住所・電話・営業時間を登録する（地図のお店登録）
2. サイトのフッターの住所・電話と、登録した内容を同じにする
3. Googleアナリティクスで測定用の番号（G- で始まる）を作り、外観 → カスタマイズ → 店情報・測定 に貼る
4. Googleサーチコンソールにサイトを登録し、サイト地図 `https://（相手の住所）/wp-sitemap.xml` を渡す
5. 公開後は週1回、どんな言葉で来ているか、どのページが読まれているかを見て、題名・説明文を直す

順位を約束するものではありません。測って、名札を直す作業です。

## いまできないこと

会員ログイン、決済、ネットショップ。地図への登録そのものは Google の画面で行います。
